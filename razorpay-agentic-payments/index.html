Development Process

From handoff
to live.

Six phases from Figma audit to production deploy — building one of Razorpay's highest-visibility product pages demanded rigorous component thinking and obsessive responsive discipline.

akshat@razorpay ~ /projects/agentic-payments
# ── 01 Figma handover audit
❯ figma export --file=agentic-v3 --tokens --components --variants
✓ 47 components · 12 variant sets · 6 breakpoints · design tokens exported
# ── 02 Component library
❯ framer build:components hero pillar-cards marquee video testimonials cta
✓ CMS-driven content · variant-aware components · partner logo system
# ── 03 Interactions & animation
❯ framer add:interactions --scroll-reveals --hover-states --marquee --video
✓ 60fps across all targets · intersection-triggered reveals · no layout shift
# ── 04 Responsive — 5 breakpoints
❯ framer breakpoints:tune --targets 390,768,1280,1440,2560
⚠ 4K scale: custom token override required for type ramp
✓ All 5 breakpoints pixel-perfect against Figma specs
# ── 05 Partner assets (10+ brands)
❯ assets integrate openai npci anthropic zomato bigbasket vi pvrinox elevenlabs sarvam
✓ Brand hierarchy applied · Razorpay primary · partners secondary
# ── 06 Production deploy
❯ framer publish --domain razorpay.com/agentic-payments --env prod
✓ Published · 0 launch issues
